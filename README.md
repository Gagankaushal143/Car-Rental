# RentalX 🚗

A full-stack car rental platform built using the MERN stack.

## Features

- User registration and login
- JWT authentication
- Protected routes
- Browse available cars
- Search and filtering
- Pagination
- Car details
- User profile
- REST APIs

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- React Router
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Deployment

Frontend: Vercel
Backend: Render
Database: MongoDB Atlas
